<b>Physics-Informed Neural Network (PINN) Solution for 1D Axial Bar Deformation</b>
</br>
• Theprimary objective of this project is to build, train, and validate a PINN to solve the 1D axial equilibrium
problem for a cantilever bar subjected to a constant distributed load q.
</br>
• Specifically modeled scenarios where the Young’s Modulus E(x) and cross-sectional Area A(x) vary linearly
along the bar’s length L.
